Intranet

An intranet is a private, internal network that uses web technologies to facilitate communication and collaboration within a single organization. Think of it as a "private internet" that is hidden from the public eye. Companies use intranets to store sensitive documents, host internal tools, and keep employees informed, all within a secure perimeter that prevents unauthorized external access.
