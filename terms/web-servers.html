🗄️ Web Servers

A web server is software and hardware that uses HTTP (Hypertext Transfer Protocol) to respond to client requests made via web browsers. It stores, processes, and delivers web pages to users.

Popular web server software includes Apache HTTP Server, Nginx, Microsoft IIS, and LiteSpeed. When you type a URL into your browser, the request travels to the web server, which then sends back the requested HTML document, images, stylesheets, or scripts.

Web servers can handle static content (HTML, CSS, images) or dynamic content (PHP, Python, Node.js applications) through server-side processing.
